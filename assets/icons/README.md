# Lucide 图标

本目录保存可复用的 [Lucide](https://lucide.dev/icons/) SVG 原件及同名透明 PNG，供 `Deck.icon()` 在本地嵌入 PowerPoint；生成过程不访问网络。

Lucide 图标使用 ISC 许可，其中部分源自 Feather 的图标还受 MIT 许可约束。本目录含有 `arrow-right`、`database`、`search` 和 `server` 等 Feather 来源图标。随附的 [LICENSE](LICENSE) 是 [Lucide 官方许可文件](https://github.com/lucide-icons/lucide/blob/main/LICENSE)，包含两种许可的版权与授权声明。

添加图标前先检查是否已有同名资源，并保留 SVG 原件、同名 PNG 与许可说明。
